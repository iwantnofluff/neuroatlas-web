# Domain extension decision

Status: decided, 9 October 2026
Date: 9 October 2026

## Decision

`neuroatlas.in` is the primary domain for the India-first launch. The company owns one other domain, `neuroatlas.org.uk`, which redirects to it permanently.

## Why not .com

The task's default for a global brand is `.com`, but `neuroatlas.com` is not available:

- It has been registered since July 2011 (GoDaddy, renewed to July 2027).
- It is the live website of Atlas Spine + Brain Surgeons, an unrelated neurosurgery practice.

Getting it would mean a private purchase from that owner, with no guarantee they will sell. Because they are also a medical brain-health business, some searches will turn up both brands whatever we do.

## Why .in suits this launch

- Google treats `.in` as targeted at India, which helps ranking for searches in India, the launch market.
- It signals a local company to Indian visitors and partners.
- It is already live and set up: the security certificate, redirects, sitemap, canonical tags and Klaviyo sending domain (`hello.neuroatlas.in`) all use it.

The trade-off: because Google ties `.in` to India, it would rank less well in other countries. That only matters once there is a global launch (see below).

Someone else holding `.com`, `.co.uk` and `.co` means visitors who guess the address could land on another site. Using `neuroatlas.in` consistently in marketing, email and print keeps this to a minimum.

## If a global launch comes later

Pick one of these at that point. No action needed now.

1. **Buy `neuroatlas.com`** if the owner will sell, and make it the global site.
2. **Use a global extension we can register now**, such as `neuroatlas.ai` or a different `.com` name, for the global site.
3. **Keep `neuroatlas.in` for India** and run the global site on the new domain, with the two linked for search engines (hreflang tags) so each country is shown the right one.

A separate India property only makes sense under option 3, once there are two markets with different content, pricing or regulation.
